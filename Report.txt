  * Measured on 5 successful cases only.

  Key findings by model:

  llama3:8b
  - Fastest but least reliable; 1 Agent 1 failure.
  - Fabricated recall URLs in Agent 3 (translated Spanish URL paths to English),
    causing 2/5 invalid links — a critical data integrity issue.
  - Preamble injection ("Here is the summary:") fixed by prompt revision.
  - Agent 3 rewrote summaries instead of copying verbatim (pre-revision).

  qwen2.5:7b
  - 100% pipeline reliability, all links valid.
  - Sentence count compliance poor on the original prompts (4 failures/6).
    Improved but not eliminated with revised prompts.
  - 1 pipe-delimited consumer_action leak (France data) in both runs.
  - Keys not translated on French data (by design after prompt revision).

  gemma2:9b
  - Perfect quality scores on all automated metrics.
  - Slowest model (~76s avg), 90% slower than llama3.
  - Manual review showed no structural issues in Agent 3 output.
  - Highest-fidelity distributor name translation (proper-cased French names).

  qwen2.5:14b
  - Perfect automated scores: 6/6 summaries, 0 pipe leaks, 0 empty hazards.
  - Fastest Agent 3 of the group (7.2s avg).
  - One critical manual finding: us_01 hazard_type incorrectly set to
    "Undeclared milk" (correct: undeclared fish/anchovies allergen). This
    passed all automated validators — a semantic accuracy gap.
  - HTML entities (&quot;, &amp;) not decoded in Agent 1 output.
  - Agent 2 for france_00 added unsolicited medical advice in Sentence 3.

--------------------------------------------------------------------------------
4. AGENT 1 TRANSLATION QUALITY (manual review)
--------------------------------------------------------------------------------

  llama3:8b    - Translated URL paths (fabricated non-existent URLs). Poor.
  qwen2.5:7b   - Mixed: some Spanish phrases left untranslated in values.
                 Inconsistent. Sentence repetition in long HTML fields.
  gemma2:9b    - Best key-value translation quality. Proper-cased names,
                 cleanest distributor/region handling.
  qwen2.5:14b  - Good value translation. Keys retained (by design).
                 HTML entities leaked through. Dates correctly preserved.

--------------------------------------------------------------------------------
5. CONCLUSIONS
--------------------------------------------------------------------------------

  BEST OVERALL ACCURACY:   gemma2:9b
    Perfect automated scores, cleanest manual output, no critical errors.
    Cost: it is the slowest model (~76s/case) and slowest on any hardware.

  BEST SPEED/QUALITY:      qwen2.5:14b
    Perfect automated scores, only ~14% slower than qwen2.5:7b, and far
    more reliable formatting than 7B. One semantic hallucination found
    (wrong allergen type) that automated validators did not catch.
    Recommended for production use if latency is acceptable.

  DO NOT USE FOR THIS TASK: llama3:8b
    Fastest clock time, but fabricates URLs, rewrites summaries, and
    produced a pipeline failure. Speed is meaningless when the output
    cannot be trusted.

  AUTOMATION GAP:
    Current quality metrics (sentence count, pipe detection, link-in-source)
    catch formatting violations but miss semantic errors like wrong hazard
    type. A ground-truth validation step is needed to reliably score accuracy
    in a food safety context.
